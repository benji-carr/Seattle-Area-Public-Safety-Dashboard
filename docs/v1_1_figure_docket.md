## Reuse boundaries

Crime choropleth and point map are layers of the same `make_map_figure()` in [crime_dashboard_figures.py](../dashboard/crime_dashboard_figures.py), not separate app figures. Adapt the shared function while preserving point-only search. Its no-state fallback uses a 365-day mappable-event window; production app calls supply the selected analysis state.

The existing calls daily series and combined calls map in [spd_dashboard_figures.py](../dashboard/spd_dashboard_figures.py) are **optional / decision pending** for v1.1 retention; they are not additional planned figures. The daily series can be reused if retained. The calls map's response hover statistic uses a different row/geography/window calculation from qualified response KPIs and requires adaptation if retained with that label. Its point dates do not control its annual choropleth summary.

There is no automatic mapping from canonical crime categories/subcategories to CAD importance bins, and no shared UOF period control yet. Integrate only supported filters; show stream coverage when dates differ. These are control/figure implementation boundaries, not missing source streams.

**National OIS comparison: DEFERRED TO v1.2.** No national comparison figure or denominator is part of this docket.
